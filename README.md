## Overview
This project covers the setup of a safe, isolated cybersecurity lab. The lab lets virtual machines communicate with each other and reach the internet without exposing the host network.

## Tasks Completed
- Installed and configured Oracle VirtualBox
- Created a NAT network for the lab environment
- Installed Kali Linux and configured its network connection
- Took a snapshot of the stable configuration

## Key Learnings
- Why an isolated lab is essential for safe security practice
- How NAT networking enables secure VM-to-VM and internet communication
- How snapshots help with testing and quick recovery

## Tools Used
Oracle VirtualBox, Kali Linux, NAT Network
